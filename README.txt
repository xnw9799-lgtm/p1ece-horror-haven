选人：左右翻掌切换，回正后再切换；握拳保持约0.45秒确认；也可点击头像、左右按钮及 CONFIRM。

摄像头需要 HTTPS 或 localhost；画面本地处理。GPU优先、CPU回退。双手入镜时锁定一只控制手。
首页和选人页统一炭灰纹理、红色粒子与红色强调色。
已检查：原图一致性、六人顺序、翻掌与握拳选人、双手锁定、拼图抓取与归位。未实测物理摄像头或浏览器视觉效果。
